# Lab 4: IoT Physical Security

**Tool:** Cisco Packet Tracer · **Focus:** IoT and physical security

## What I did
1. Connected IoT security devices to the network.
2. Registered them on an **IoT registration server** so they could be managed centrally.
3. Tested how the devices work together, with sensors triggering alarms and responses.

## Security takeaways
- IoT devices are network endpoints and need the same care: unique credentials, central management, and their own network segment.
- Physical security controls (sensors, alarms, door access) are part of the security program, not separate from it.
- Unmanaged IoT devices are a common way into a network, so inventory and registration come first.
